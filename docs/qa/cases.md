# Baseline test cases

Case count: **49** (`BL-001` through `BL-049`).

Regression cases are the “must not regress” list in `docs/testing-release.md`: BL-007, BL-016, BL-019, BL-021, BL-023, BL-026, BL-031, BL-033. A failure on any of those blocks TestFlight exit.

The manual script in `docs/qa/manual-script.md` walks the version-1 path and the privacy cases. Widget, golden, and API layers run in CI.
