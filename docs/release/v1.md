# Baseline 1.0

Version 1 is a learning app a beginner can use on a phone without a live court booking system. App Store submission still needs an Apple Developer account, signing, and a privacy policy URL.

## What a player can do

- Create a local account with Apple, Google, or email, then pass an age check.
- Answer onboarding and get a first-week plan.
- Take the level 1 course: introduction, court, scoring, equipment, grips, ready position, forehand, backhand, serve, volley, and etiquette.
- Continue into level 2 rallying, forehand fundamentals, and footwork. Level 3 lessons stay behind Premium.
- Log drills and matches. Progress and the streak stay on the phone.
- Look up sample courts, players, coaches, and stores.
- Read an equipment guide that labels sponsored rows.
- Turn discovery off, control notifications, and delete the account.

## What is not in this build

- A charge through the App Store. Premium unlocks on the phone and says so.
- Apple and Google token checks on the server. Those routes return “not configured” until the developer credentials exist.
- A live map SDK. Courts are a list with sample Austin places.
- Licensed technique video. Lessons are written so they stand without a clip.
- Postgres as the running store. The API saves accounts to `services/api/data/store.json`. The SQL migrations are the production database and can be applied when `DATABASE_URL` is set.

## Run

```bash
cd apps/mobile && flutter pub get && flutter run
cd services/api && npm install && npm test && npm run dev
```

Database, when Postgres with PostGIS is running:

```bash
export DATABASE_URL="postgres://baseline:local-dev-only@127.0.0.1:5432/baseline"
cd services/api
npm run db:migrate
npm run db:seed
```

## Before TestFlight

1. Add the Apple Team ID and a unique bundle id.
2. Host a privacy policy and terms, and put the URLs in the app and App Store Connect.
3. Turn on Sign in with Apple in the developer portal.
4. Create the subscription in App Store Connect and replace the on-device unlock.
5. Answer the age-rating questions. Messaging between players points to 17+.
6. Confirm the location purpose string matches the in-app explanation.
7. Run the manual script in `docs/qa/manual-script.md`.
