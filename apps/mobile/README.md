# Baseline mobile

Flutter client for Baseline. iOS is the first target. The same UI is ready for Android later.

Lessons, drills, glossary terms, the forehand-into-the-net coach rule, and 101
offline video clips are bundled with the mobile app, so this shell runs
offline. The library includes licensed player/human footage, including 31 new
Pexels additions, plus Baseline diagrams. Clips support the written coaching;
not every clip is an exact technique demonstration. Sign-in is local: Apple and
Google continue straight through, and any email code is accepted. Players under
16 are stopped at the age gate.

## Run

```bash
cd apps/mobile
flutter pub get
flutter run
```

## Tests

```bash
cd apps/mobile
flutter test
```
