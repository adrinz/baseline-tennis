# Baseline mobile

Flutter client for Baseline. iOS is the first target. The same UI is ready for Android later.

Lessons, drills, glossary terms, and the forehand-into-the-net coach rule are bundled from the seed catalog, so this shell runs offline. Sign-in is local: Apple and Google continue straight through, and any email code is accepted. Players under 16 are stopped at the age gate. No video file is embedded.

## Run

```bash
cd apps/mobile
flutter pub get
flutter run
```

## Tests

```bash
cd apps/mobile
flutter test
```
